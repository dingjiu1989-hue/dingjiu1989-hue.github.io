做教程、录演示、汇报工作——屏幕录制是高频需求。这些工具从简单录屏到专业剪辑全覆盖。 录屏工具 工具 价格 亮点
OBS Studio 免费开源 最强大的免费录屏+直播工具，支持多场景切换
CleanShot X $29 一次性 macOS 最强，截图+录屏+标注+OCR+滚动截图一体
Loom 免费 25 个视频 即录即分享，自动生成链接，适合团队沟通

轻量剪辑
  • Descript — AI 视频编辑器，像编辑文档一样编辑视频，自动去语气词和沉默。免费版够个人用。
  • CapCut (剪映国际版) — 免费且功能强大，自动字幕生成极准，模板丰富。
  • DaVinci Resolve — 专业级免费剪辑软件，调色功能业界顶尖，学习曲线陡但值得。
  • iMovie / Clipchamp — 系统内置，零成本完成简单剪辑。

场景推荐

  • 录代码教程 → OBS + DaVinci Resolve

  • 做产品演示 → Screen Studio
  • 短视频/社媒内容 → CapCut
