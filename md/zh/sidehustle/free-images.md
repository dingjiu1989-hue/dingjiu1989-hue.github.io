# 免费可商用图片资源汇总

做设计、写文章、做视频都需要配图。付费图库太贵，版权问题又麻烦。以下都是真正免费可商用的图片资源。 综合图库（Free + CC0） 网站| 特点| 是否需要署名  
---|---|---  
Unsplash| 高质量摄影，审美在线，量大| 不需要  
Pexels| 照片+视频，中文搜索还行| 不需要  
Pixabay| 照片+插画+矢量图+视频| 不需要  
Freepik| 大量矢量图和 PSD，部分免费| 需要（免费版）  
特定风格

  * **Illustrations (unDraw)** — 开源 SVG 插画，可自定义颜色，适合产品页和 PPT。
  * **Humaaans** — 人物插画组件，可自由组合场景。
  * **Nappy** — 专注黑人/棕色人种的高质量照片，多元文化素材。
  * **The Gender Spectrum Collection** — LGBTQ+ 主题的免费图库。
