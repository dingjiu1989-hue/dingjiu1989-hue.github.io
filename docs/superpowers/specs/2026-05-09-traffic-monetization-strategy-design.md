# AI自习室 流量变现战略设计

**日期**: 2026-05-09
**状态**: 执行中

## 核心判断

285 篇文章，AdSense 审核中，但 GSC 数据为空——不知道索引状态，不知道排名，不知道流量。当前瓶颈不是内容量，是 Google 是否认可这个站。策略必须是：诊断 → 建权威 → 优化 → 变现。

## Phase 1: GSC 数据诊断

**目标**: 用已有 GSC API token 拉取索引覆盖率 + 搜索查询数据
**交付**: `data/gsc-performance.json` + 健康报告更新
**验收**: 能回答"多少页面被索引、top 10 查询、展示/点击趋势"

## Phase 2: Dev.to 主引擎

**目标**: Dev.to 从"有脚本"变成持续流量源
**逻辑**: Dev.to DA 90+，文章带 canonical 回本站，传递权威信号 + 直接引荐流量
**执行**:
- 筛选 20-30 篇高 CPC 英文精华文章
- 每日 1-2 篇推送到 Dev.to
- GitHub Actions 自动化
**验收**: Actions 里 syndicate 任务成功运行

## Phase 3: 内容精修

**目标**: 不新增文章，打磨精华 30-50 篇
**执行**:
- 基于 GSC 数据选高潜文章
- 重写标题/meta（主关键词前置）
- 补齐内链网
- 低质重复内容 noindex
**验收**: 每目录页至少 5 篇深度互链文章

## Phase 4: 变现观察

**目标**: AdSense 通过后不铺满广告，先验证行为
**执行**:
- 文章底部单广告单元
- 工具/资源类文章加 affiliate
- 观察 30 天后调整
**验收**: AdSense 收入数据 + affiliate 点击数据

## 不做

- 不批量生产新文章
- 不扩展中文站
- 不改架构
