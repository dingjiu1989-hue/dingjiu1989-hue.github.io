# 论坛风格资料库 — 设计文档

## 概述

在 GitHub Pages 上搭建一个论坛风格（BBS）的静态资料库，三层页面结构，SEO 友好。

- **地址**: https://dingjiu1989-hue.github.io/
- **仓库**: dingjiu1989-hue/dingjiu1989-hue.github.io
- **技术栈**: 纯静态 HTML/CSS（无框架，无构建工具）

## 页面结构

```
首页 (index.html)
├── 技术教程 (/tech/index.html)
│   ├── 文章1 (/tech/git-cheatsheet.html)
│   └── 文章2 (/tech/vscode-plugins.html)
├── 副业资源 (/sidehustle/index.html)
│   └── ...
└── 工具推荐 (/tools/index.html)
    └── ...
```

### 三层结构

| 层级 | 模板 | 内容 |
|------|------|------|
| 首页 | `index.html` | 版块列表 + 每版块最新 3-5 帖 + 站点统计 |
| 分类页 | `<category>/index.html` | 面包屑 + 该版块全部帖子列表 |
| 详情页 | `<category>/<slug>.html` | 面包屑 + 文章正文 + 相关推荐 |

## 页面组件

### 全局
- **顶部导航栏**: logo + 导航链接 + 搜索框（装饰性）
- **面包屑**: 首页 > 分类 > 文章标题
- **页脚**: 版权 + 站点信息

### 首页
- Hero 区域: 站名 + 简介 + 版块数/文章数统计
- 统计数据条: 今日/昨日/总帖数
- 版块卡片: 图标 + 版块名 + 描述 + 帖子数 + 最新帖子列表
- 帖子行格式: [置顶/热门标记] 标题 回复数 日期

### 分类页
- 版块标题 + 描述 + 总帖数
- 帖子表格: 置顶 | 标题 | 回复 | 最后更新
- 排序（装饰性下拉框）
- 可选分页（内容多时手动拆分）

### 文章详情页
- 标签（置顶标记 + 分类标签）
- 标题 + 元数据（日期/阅读量/回复数）
- 文章正文
- 相关推荐（同分类下 2-4 篇）

## SEO 策略

- 每个页面独立的 `<title>` + `<meta description>`
- 语义化 HTML: `<article>`, `<nav>`, `<main>`, `<header>`
- 面包屑使用 Schema.org BreadcrumbList 结构化数据
- 文章页使用 Schema.org Article 结构化数据
- `sitemap.xml` 自动包含所有页面
- `robots.txt` 允许所有爬虫
- 页面内链: 面包屑 + 相关推荐 + 分类页链接

## 新增文章流程

1. 在对应分类目录下创建 `article-slug.html`
2. 复制文章模板，填入标题、描述、正文
3. 更新分类页 `index.html` 的帖子列表
4. 如果是重要文章，更新首页最新帖子列表
5. 更新 `sitemap.xml`

三个阶段:
- **MVP**: 3 个版块 × 2 篇文章 = 6 篇文章
- **扩展**: 5 个版块 × 5 篇文章 = 25 篇文章
- **成熟**: 每个版块 10+ 篇 + 分页

## 约束

- 纯静态，无后端，无数据库
- 首页帖子列表需手动维护（或后续用 JS 从 sitemap 动态加载）
- 无评论系统（可后续接入 Giscus）
- GitHub Pages 禁止商业广告

## 注意事项

- 帖子列表中的"回复数"为静态手写数字，用于论坛视觉风格，不代表真实评论。后续可接入 Giscus 实现真实评论
- 首页"最新帖子"列表需手动维护，每次新增文章时同步更新

## 非目标

- 后台管理面板
- 搜索功能（MVP 阶段用浏览器 Ctrl+F）
