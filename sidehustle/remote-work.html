远程工作平台大盘点

By AI自习室 · 2026-05-20 · 1 分钟阅读 · 0 次浏览 · 377 字
远程工作不再是少数人的特权。这里整理国内外主流的远程工作平台，从接单到全职，覆盖各个层次。 国际平台 平台 定位 佣金
Upwork 最大自由职业市场，各类工种 5%-20%
Fiverr 服务化交易，卖家发布"服务套餐" 20%
Toptal 高端技术人才，通过率仅 3% 平台定价
Freelancer 项目竞标模式，价格竞争激烈 10%
国内平台
  • 电鸭社区 (eleduck.com) — 国内最大远程工作社区，职位质量高，偏技术岗。
  • V2EX 酷工作节点 — 偶有远程岗发布，需常刷新。
  • 圆领 (yuanling.com) — 字节系远程工作平台，偏设计/开发。
  • 甜薪工场 — 偏新媒体、运营、设计类远程兼职。

全职远程招聘网站

  • Remote OK — 全球远程职位聚合，更新频繁。
  • We Work Remotely — 老牌远程招聘站，职位质量稳定。
  • Arc.dev — 面向开发者的远程工作平台，需通过技术面试。
  • Remotive — 主要为欧美公司，技术岗居多。

新手建议

  1. 先完善英文简历和作品集 — 国际平台英语是基本门槛
  2. 从小单做起 — 积累好评后再接大单，不要急着报高价
  3. 选择垂直领域 — 全栈不如一个细分方向深入
  4. 注意时区和税务 — 跨国远程涉及外汇结算和个人报税
