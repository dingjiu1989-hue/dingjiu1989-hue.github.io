GitHub Pages 演示

用 Git 仓库免费托管静态网站

这是什么？

GitHub Pages 是 GitHub 提供的免费静态网站托管服务。 只要把 HTML/CSS/JS 文件推送到仓库，GitHub 就会自动构建并部署成一个可访问的网站。

部署流程

  1. 在 GitHub 创建仓库，名称为 用户名.github.io（必须完全一致）
  2. 把本仓库 push 上去
  3. 等待 1-2 分钟，访问 https://用户名.github.io 即可看到这个页面

手动操作步骤

# 1. 在 GitHub.com 上创建新仓库，名称设为：你的用户名.github.io

# 2. 把本地代码推送上去
git remote add origin git@github.com:你的用户名/你的用户名.github.io.git
git branch -M main
git add .
git commit -m "初始页面"
git push -u origin main

# 3. 在浏览器打开
# https://你的用户名.github.io

GitHub Pages 也支持 Hugo、Jekyll、Next.js 等静态站点生成器。

三种部署方式

用户站点 用户名.github.io 仓库 每个账号一个
项目站点 任意仓库设置中开启 Pages 无限个
自定义域名 添加 CNAME 文件 + DNS 配置 支持 HTTPS
